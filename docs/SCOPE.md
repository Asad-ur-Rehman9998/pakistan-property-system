# MOST IMPORTANT RULE

**Do not add random features simply to make the application look large.**

Every feature must answer:

> Does this make buying/selling property in Pakistan safer, easier, clearer, or more accessible?

If **no**:

**Do not build it.**

Map: `src/lib/product/rule.ts`.

This filter sits above polish, phase checklists, and “nice to have” ideas. Guest `/check` stays account-free. Papers stay on the phone. Due diligence stays due diligence — not a listing board, CRM, chatbot, or marketplace.
